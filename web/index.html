How it runs

The original game was Flash content inside a Windows wrapper. This edition plays the original files with Ruffle, an open-source Flash Player emulator, with a few small fixes so it works in a browser:

  • Saves that went to the Windows registry now go to this browser's local storage.
  • A startup loop that froze browsers was removed.
  • Text boxes were adjusted so dialogue shows the way it did in Flash Player.
